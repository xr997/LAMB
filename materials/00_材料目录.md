## 关键事实摘要

- 软件形态：Python 可安装库 + 命令行软件 `lamb`。
- 主要功能：多文档研究问答、批量文档处理、结构化字段抽取、安全可信处理、长文档分块、审计清单生成。
- 可执行入口：`lamb scan`、`lamb research`、`lamb extract`、`lamb batch`。
- 第三方引用方式：`from lamb import ...`，或通过 `pip install git+https://github.com/xr997/LAMB.git` 安装。
- 有效生产代码行数：2337 行，不含注释和空行，统计范围为 `lamb/`、旧兼容模块及服务端/客户端代码。
