## 2. 安装步骤说明

### 2.1 克隆项目

```bash
git clone https://github.com/xr997/LAMB.git
cd LAMB
```

### 2.2 安装依赖和本地包

```bash
pip install -e .
```

项目通过 `pyproject.toml` 声明依赖和命令行入口，安装后会生成 `lamb` 命令。

### 2.3 直接从 GitHub 安装

第三方项目或用户也可以直接安装：

```bash
pip install git+https://github.com/xr997/LAMB.git
```

### 2.4 配置大模型服务

复制环境变量示例：

```bash
cp .env.example .env
```

在 `.env` 中配置：

```env
LLM_API_KEY=your_api_key_here
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-chat
```

说明：

- `LLM_API_KEY`：OpenAI-compatible API Key。
- `LLM_BASE_URL`：OpenAI-compatible 服务地址。
- `LLM_MODEL`：默认模型名称，也可通过 CLI 的 `--model` 参数覆盖。

## 3. 命令行使用说明

### 3.1 查看帮助

```bash
lamb --help
```

主要命令：

- `lamb scan`：扫描资料夹。
- `lamb research`：跨文档研究问答。
- `lamb extract`：结构化字段抽取。
- `lamb batch`：批量文档处理。
- `lamb version`：查看版本。

### 3.2 扫描资料夹

```bash
lamb scan data/inputs
```

可选参数：

- `--include-hidden`：包含隐藏文件和文件夹，但 `.env` 等敏感文件仍会被拒绝。
- `--max-file-size-mb`：限制单文件大小。
- `--hash`：计算支持文件的 SHA-256。

### 3.3 多文档研究问答

```bash
lamb research data/inputs --question "这些文档的共同结论是什么？"
```

常用参数：

- `--output-dir data/outputs`：指定输出目录。
- `--dry-run`：不调用大模型，只预览流程。
- `--strict-security`：跳过高风险 Prompt 注入文档。
- `--redact`：发送给大模型前脱敏常见敏感信息。
- `--model deepseek-chat`：指定模型名称。
- `--max-chars 12000`：设置分块字符数上限。

### 3.4 结构化字段抽取

```bash
lamb extract data/inputs --fields "姓名,分数,评语,主要问题" --format csv
```

输出：

- `*_extraction.csv` 或 `*_extraction.json`。
- `*_manifest.json`。
- `*_output_index.md`。

### 3.5 批量文档处理

```bash
lamb batch data/inputs --instruction "请为这份文档写一段 200 字摘要" --format md
```

可选输出格式：

- `md`
- `txt`
- `docx`

## 4. Python SDK 使用说明

LAMB 可被第三方 Python 程序引用：

```python
from lamb import answer_over_directory, extract_fields, process_directory, scan_documents

records = scan_documents("data/inputs")

qa = answer_over_directory(
    input_dir="data/inputs",
    question="这些文档的共同结论是什么？",
    output_dir="data/outputs",
    redact=True,
)

extraction = extract_fields(
    input_dir="data/inputs",
    fields=["姓名", "分数", "评语"],
    output_dir="data/outputs",
)

batch = process_directory(
    input_dir="data/inputs",
    instruction="请为每份文档生成结构清晰的摘要",
    output_format="md",
)
```

## 5. 输出文件说明

不同工作流会生成不同文件：

| 输出文件 | 说明 |
| --- | --- |
| `*_research.md` | 多文档问答报告 |
| `*_extraction.csv` | 字段抽取 CSV 表格 |
| `*_extraction.json` | 字段抽取 JSON 文件 |
| `*_processed.md` | 单文件批处理结果 |
| `*_manifest.json` | 运行审计清单 |
| `*_output_index.md` | 输出索引 |
