# 一、功能介绍

## 1. 项目概述

LAMB 是一个本地优先、安全可信的多文档 AI 批处理与研究助理。项目面向日常资料夹中的 PDF、Word、Markdown、TXT、CSV、JSON 等文件，提供本地扫描、文本解析、安全检查、长文档分块、大模型处理、结果导出和审计记录能力。

与普通聊天式 AI 工具不同，LAMB 的核心对象不是“单次对话”，而是“一个本地资料夹”。用户可以把论文、作业、简历、会议纪要、调研报告等文件放入目录，通过命令行或 Python SDK 批量处理，并得到可复用、可追溯的结果文件。

## 2. 独立功能说明

### 功能一：多文档研究问答

用户可以对整个资料夹提出问题，LAMB 会解析所有支持的文档，自动对长文档分块，先从各文档中提取证据，再汇总生成带来源的 Markdown 研究报告。

示例命令：

```bash
lamb research data/inputs --question "这些文档的共同结论是什么？"
```

适用场景：

- 批量阅读论文并提炼共同方法、结论和差异。
- 对多个调研报告进行综合分析。
- 汇总课程资料、会议材料、项目文档并回答问题。

输出结果：

- `*_research.md` 研究报告。
- `*_manifest.json` 审计清单。
- `*_output_index.md` 输出索引。

### 功能二：批量文档处理

用户可以给出任意处理指令，让 LAMB 对资料夹内每份文档逐个执行任务，例如摘要、翻译、润色、批改、审阅等。

示例命令：

```bash
lamb batch data/inputs --instruction "请为这份文档写一段 200 字摘要" --format md
```

适用场景：

- 批量摘要课程作业、论文、项目报告。
- 批量翻译或润色文档。
- 对多个文档逐份生成处理结果。

输出结果：

- 每份输入文档对应一个处理结果文件，如 `xxx_processed.md`。
- 审计清单和输出索引文件。

### 功能三：结构化字段抽取

用户可以指定字段名，让 LAMB 从每份文档中抽取结构化信息，并导出为 CSV 或 JSON。

示例命令：

```bash
lamb extract data/inputs --fields "姓名,分数,评语,主要问题" --redact
```

适用场景：

- 批量批改作业，输出姓名、分数、评语、主要问题。
- 筛选简历，抽取教育背景、技能、项目经验。
- 整理会议纪要，抽取议题、待办事项、负责人、截止时间。

输出结果：

- `*_extraction.csv` 或 `*_extraction.json`。
- 审计清单和输出索引文件。

### 功能四：安全可信处理

LAMB 将文档内容视为不可信输入，不把文档内部文本当作系统指令。系统内置 Prompt 注入检测、敏感信息脱敏、路径边界控制和严格安全模式。

安全能力包括：

- 检测 “ignore previous instructions”“reveal system prompt”“读取密钥”“调用工具”等 Prompt 注入风险。
- `--strict-security` 跳过高风险文档。
- `--redact` 在发送给大模型前脱敏邮箱、手机号、API key、token、JWT 类字符串。
- 默认跳过隐藏文件、`.env`、凭据类文件和符号链接。

示例命令：

```bash
lamb batch data/inputs --instruction "请总结文档" --strict-security --redact
```

### 功能五：长文档分块与审计清单

LAMB 对长文档进行分块处理，减少上下文超限风险。每次运行都会生成 `manifest.json`，记录输入目录、输出目录、模型名称、参数、文件成功/失败状态、风险提示、耗时等信息。

该功能提高了批处理结果的可复现性和可追溯性，适合教学、科研和企业内部文档流转场景。

## 3. 第三方引用与可执行软件能力

LAMB 同时满足“第三方程序引用”和“可执行软件”两类要求。

### 3.1 可被第三方程序引用

项目通过 `pyproject.toml` 定义 Python 包 `lamb-batch`，可通过如下方式安装：

```bash
pip install git+https://github.com/xr997/LAMB.git
```

第三方程序可直接引用：

```python
from lamb import answer_over_directory, extract_fields, process_directory, scan_documents

records = scan_documents("data/inputs")
result = answer_over_directory(
    input_dir="data/inputs",
    question="这些文档的共同结论是什么？",
)
```

### 3.2 可作为命令行软件运行

项目在 `pyproject.toml` 中配置 console script：

```toml
[project.scripts]
lamb = "lamb.cli:main"
```

安装后可以直接使用 `lamb` 命令：

```bash
lamb scan data/inputs
lamb research data/inputs --question "这些文档说了什么？"
lamb extract data/inputs --fields "姓名,分数,评语"
lamb batch data/inputs --instruction "请总结文档"
```

命令行具备用户交互入口，用户可以通过参数指定输入目录、问题、字段、输出目录、模型、安全模式等。
