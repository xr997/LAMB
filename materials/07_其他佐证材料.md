## 2. 真实应用案例

### 案例名称：课程作业与论文资料批量处理

### 应用场景

教师或学生将作业、论文笔记、汇报材料放入 `data/inputs` 目录，希望批量完成以下任务：

- 扫描目录内支持文件。
- 对多个文档提出综合问题。
- 从作业中抽取姓名、分数、评语等字段。
- 为每份文档生成摘要。
- 记录每次运行的输入、输出、失败和风险提示。

### 使用方式

扫描目录：

```bash
lamb scan data/inputs
```

批量批改作业：

```bash
lamb extract data/inputs --fields "姓名,分数,评语,主要问题" --redact
```

批量阅读论文或报告：

```bash
lamb research data/inputs --question "这些文档的共同结论是什么？"
```

逐文件摘要：

```bash
lamb batch data/inputs --instruction "请为这份文档写一段摘要" --format md
```

### 处理效果

运行后可得到：

- CSV 批改表或字段抽取表。
- Markdown 研究报告。
- 每份文档对应的处理结果文件。
- `manifest.json` 审计文件。
- `output_index.md` 输出索引。

该案例体现了 LAMB 在教学和科研材料处理中的现实价值：减少重复性人工整理，提升文档处理效率，并通过审计记录和安全防护提高可信度。
