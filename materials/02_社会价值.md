# 二、社会价值

## 1. 项目解决的现实痛点

LAMB 面向教学、科研、办公和知识管理中的高频文档处理问题。现实场景中，用户常常需要处理一个资料夹内的几十份甚至上百份文档，例如学生作业、论文资料、会议纪要、简历、调研报告等。网页端 AI 工具适合处理单个文件，但在批量场景中存在以下问题：

- 文件需要逐个上传，效率低，容易遗漏。
- 长文档容易超过上下文限制，回答稳定性不足。
- 大模型输出难以批量保存为 CSV、Markdown、DOCX、JSON 等格式。
- 处理过程缺少审计记录，无法追踪成功、失败、跳过和风险提示。
- 文档中可能存在 Prompt 注入文本，诱导模型忽略系统指令或泄露信息。

LAMB 将资料夹级文档处理抽象为“扫描、解析、安全检查、分块、大模型工作流、导出、审计”的完整流程，使普通用户无需编写复杂脚本，也能完成可复现的批量文档智能处理。

## 2. 典型社会应用价值

### 2.1 教学场景

教师可将学生作业放入同一目录，通过结构化抽取能力生成批改表。例如抽取姓名、分数、评语、主要问题等字段，减少重复性批改和登分工作。

示例命令：

```bash
lamb extract data/homework --fields "姓名,分数,评语,主要问题" --redact
```

价值体现：

- 降低教师批量整理作业反馈的时间成本。
- 输出 CSV 表格，便于后续导入 Excel 或教学管理系统。
- 使用 `--redact` 可减少学生手机号、邮箱等信息进入大模型请求的风险。

### 2.2 科研与学习场景

研究人员或学生可对多个论文、读书笔记、调研材料进行跨文档问答，形成带来源的 Markdown 报告。

示例命令：

```bash
lamb research data/papers --question "这些论文的方法有什么共同点和差异？"
```

价值体现：

- 减少重复阅读和手工摘录。
- 输出报告保留来源文件，便于复核。
- 长文档分块降低上下文超限风险。

### 2.3 办公与组织协作场景

企业或团队可将会议纪要、调研报告、项目文档批量整理为待办表、总结报告或逐文件摘要。

示例命令：

```bash
lamb extract data/meetings --fields "议题,待办事项,负责人,截止时间"
```

价值体现：

- 降低会议纪要整理成本。
- 输出结构化待办事项，便于团队跟进。
- 每次处理生成审计清单，便于追踪处理结果。

### 2.4 AI 安全与可信使用价值

LAMB 的安全特色不是传统通信层加密，而是面向大模型应用层的可信处理能力。项目将文档视为不可信证据，检测 Prompt 注入和敏感信息风险，适合在教学、科研和办公环境中演示“安全使用大模型处理本地文档”的实践范式。

## 4. 被其他软件引用、依赖和关联的说明

LAMB 已具备被第三方软件引用和依赖的标准形式：

1. **Python 包依赖方式**  
   第三方项目可通过 GitHub URL 依赖本项目：
   ```bash
   pip install git+https://github.com/xr997/LAMB.git
   ```

2. **SDK 引用方式**  
   第三方 Python 程序可直接导入：
   ```python
   from lamb import process_directory, answer_over_directory, extract_fields
   ```

3. **命令行集成方式**  
   第三方脚本、自动化任务或教学演示环境可调用：
   ```bash
   lamb research docs --question "这些文档的共同结论是什么？"
   ```

4. **开源关联证据**  
   GitHub Fork、Pull Request、Contributors、Network 页面可作为被开源社区关联和协作的证据。当前项目已有 3 个 Fork 和 4 位贡献者。

说明：如评审要求“被其他独立软件项目正式依赖”的截图，可后续补充第三方项目 `requirements.txt`、`pyproject.toml` 或 GitHub Dependents 页面截图。当前材料先以项目可安装包形态、Fork/PR 关联、社区贡献记录作为支撑证据。
