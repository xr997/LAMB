# 五、代码截图

## 1. 代码规模说明

比赛要求独立开发代码行数不少于 1000 行，不包括注释和空行，不包括第三方库引用。

当前项目统计范围为：

- `lamb/`：新版核心包，包括 CLI、SDK、工作流、安全、解析、写出、审计等模块。
- `client/`：旧版交互终端客户端。
- `core/`：旧版工作流和 LLM 引擎兼容模块。
- `parsers/`：旧版解析器。
- `server/`：MCP 服务端原型。
- `templates/`：提示词模板加载器。
- `utils/`：文件工具。
- `writers/`：旧版写出器。

统计命令：

```bash
find lamb client core parsers server templates utils writers -name '*.py' -print0 \
  | xargs -0 awk 'NF && $1 !~ /^#/ {count++} END {print count+0 " non-comment non-empty production Python lines"}'
```

当前统计结果：

```text
2337 non-comment non-empty production Python lines
```

该统计不包含：

- 第三方库源码。
- Python 缓存文件。
- `tests/` 测试代码。
- `data/inputs`、`data/outputs` 数据文件。
- 空行和以 `#` 开头的注释行。

## 2. 核心代码结构

新版核心代码集中在 `lamb/` 包内：

| 文件 | 作用 |
| --- | --- |
| `lamb/cli.py` | 命令行入口，提供 `scan`、`research`、`extract`、`batch` |
| `lamb/workflow.py` | 核心工作流，负责批处理、研究问答、字段抽取 |
| `lamb/security.py` | Prompt 注入检测、敏感信息脱敏、路径安全辅助 |
| `lamb/parsing.py` | TXT、Markdown、CSV、JSON、DOCX、PDF 解析 |
| `lamb/chunking.py` | 长文档分块和 token 估算 |
| `lamb/llm.py` | OpenAI-compatible LLM 客户端 |
| `lamb/manifest.py` | 运行审计清单生成 |
| `lamb/writers.py` | Markdown、TXT、DOCX、CSV、JSON 输出 |
| `lamb/models.py` | SDK 结果对象和数据结构 |
| `lamb/prompts.py` | 安全 Prompt 构造 |
| `lamb/scanning.py` | 本地资料夹扫描 |

## 3. 关键代码说明

### 3.1 CLI 入口

`lamb/cli.py` 通过 `argparse` 暴露命令行能力，包括：

- `lamb scan`
- `lamb research`
- `lamb extract`
- `lamb batch`

该文件体现软件具备用户交互功能。

### 3.2 核心工作流

`lamb/workflow.py` 是项目最核心模块，包含：

- `process_file`
- `process_directory`
- `answer_over_directory`
- `extract_fields`
- `_prepare_record`

其中 `_prepare_record` 统一处理解析、风险检测、脱敏、分块和空文档判断，提升工作流稳定性。

### 3.3 安全模块

`lamb/security.py` 包含：

- `PromptInjectionDetector`
- `SensitiveDataRedactor`
- 路径安全判断函数。

该模块支撑 Prompt 注入检测、敏感信息脱敏和隐藏/敏感文件跳过。

### 3.4 输出和审计

`lamb/manifest.py` 和 `lamb/writers.py` 负责生成：

- 运行清单 `manifest.json`。
- 输出索引 `output_index.md`。
- 研究报告、字段抽取表、逐文件处理结果。
